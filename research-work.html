Airfoil Aerodynamic Optimization via DDPM

UBC Computational Multiphysics Lab • Oct 2025 → Present • ML · CFD · Python · High-Performance Computing

Open PDF in New Tab ↗ ⬇️ Download Paper/Report

Research Overview

Spearheading the development of a reward-directed Denoising Diffusion Probabilistic Model (DDPM) framework for generative aerodynamic shape optimization[cite: 1]. The framework benchmarks against traditional Bayesian optimization and genetic algorithms, achieving ~30% improvement in lift-to-drag ratio over baseline geometries using high-performance computing (HPC) clusters[cite: 1].

Key Contributions

  • Aerodynamic Surrogate Modeling: Built an Artificial Neural Network (ANN) integrated with XFOIL for rapid, low-cost aerodynamic performance evaluations during iterative generation[cite: 1].
  • High-Fidelity CFD Validation: Developed an automated OpenFOAM and Gmsh pipeline using k-ω SST turbulence modeling for high-accuracy numerical verification of optimized airfoil profiles[cite: 1].
  • Inverse Design & Diffusion: Formulated custom conditioning and loss functions to steer generative diffusion trajectories directly toward high L/D geometric solutions[cite: 1, 2].

Tools & Technologies

Python (PyTorch, Pandas, Plotly), OpenFOAM, Gmsh, XFOIL, Bayesian Optimization, Genetic Algorithms, HPC/Slurm[cite: 1].
