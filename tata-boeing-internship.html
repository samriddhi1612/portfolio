Overview

Worked in manufacturing automation for the Boeing 737 MAX Vertical Fin production program[cite: 1, 2]. Developed software pipelines to parse complex machining routines, optimized KUKA robotic drilling cell accuracy, and standardized production-wide digital manufacturing records[cite: 1, 2].

Key Technical Projects

  • NC Code Parsing & Telemetry: Built a Python (Pandas/Plotly) framework alongside an Excel VBA macro to extract and visualize 15+ machining parameters across 100k+ lines of SINUMERIK 840D NC code, cutting retrieval time by up to 90%[cite: 1].
  • EOAT Kinematic Transformation: Modeled End-of-Arm Tooling (EOAT) rotation with rotation matrices to correct robotic coordinate transformations, improving physical drill point accuracy by ~50%[cite: 1].
  • CAD Part Verification: Executed dimensional analysis across 50+ CATIA V5 structural components utilizing Boolean operations and aerospace tolerance validation suites[cite: 1].
  • Process Standardization: Audited and standardized 800+ Manufacturing Instruction Sheets in SAP HANA, eliminating redundant and conflicting production records[cite: 1].

Tools & Technologies

KUKA Robotics, CATIA V5, SINUMERIK 840D NC Code, Python (Pandas, Plotly), Excel VBA, SAP HANA, Coordinate Transformations[cite: 1, 2].
